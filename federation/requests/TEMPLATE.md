# Request N. Short name

**From:** `unit-id` · **Amount:** what is asked · **Cycle:** YYYY-MM

> Copy to `n-short-name.md` and open as a pull request before the cycle window
> closes. The five sections below are not a form to fill politely. A request
> missing any of them is returned without being judged on merit
> ([DAF-000 §6](../../dafp/daf-000-federation-constitution.md#6-resources)).
> Delete this block.

## 1. What was tried first

Why no other route exists. Your own resources, the unit's treasury, a side project, an external grant. What was attempted, and what happened.

Federation support is a last resort. This section is where that rule is actually enforced, and it is the one most requests fail.

## 2. What this serves

Which main project, concretely. Not the ecosystem in general. The specific work that moves because this is funded.

## 3. What it funds

The function or module, defined so a stranger can tell whether it was done.

**Builds on:** the previous deliveries this continues, by link. If this is the first function of a new tree, say so. A tree with no history is not disqualified, it is just judged on its own.

## 4. The amount, and partial funding

What is asked, and what happens with less: what still gets delivered, or why less delivers nothing at all. "Anything helps" is not an answer. A request that cannot say what half of it buys has not been thought through.

## 5. How it will be evidenced

What will exist when this is finished, and by when. This is what the next assembly checks, and what the next request from this unit is judged against.
